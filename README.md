## Qué es

Una red se **decide**, se **construye** y se **mantiene**. Este material recorre los tres lados del oficio con el mismo método: primero se entiende la idea, después se consulta el detalle, se aplica en casos reales y se comprueba lo aprendido.

## Seis formas de estudiar cada unidad

Cada unidad trae las mismas piezas, pensadas para momentos distintos:

| Pieza | Para qué sirve | Tiempo |
| :--- | :--- | :--- |
| **Entender** · Resumen conceptual | La idea desde cero, con analogías y sin tablas de datos. | 15 min |
| **Consultar** · Resumen técnico | Cifras, normas, tablas y procedimientos para volver a ellos. | 1 a 2 h |
| **Aplicar** · Casos prácticos | Seis casos con solución paso a paso y rúbrica para autoevaluarte. | 1,5 a 2,5 h |
| **Comprobar** · Autoevaluación | Preguntas con la explicación de cada error habitual. | 40 a 50 min |
| **Memorizar** · Tarjetas de repaso | Cifras y definiciones para repaso espaciado. | 15 min |
| **Practicar** · Guía de laboratorio | Cinco prácticas con herramientas gratuitas. | una tarde cada una |

> [!TIP]
> La regla de estudio es siempre la misma: **primero entiendes, después recuerdas, después lo explicas en voz alta.** Si no puedes explicar una unidad en cinco minutos sin apuntes, todavía no la tienes.

## Procedencia y alcance

> [!IMPORTANT]
> **No es un material oficial.** Parte del programa formativo publicado en el BOE (Real Decreto 1531/2011, modificado por el Real Decreto 628/2013, anexo del certificado IFCT0410, BOE-A-2011-19503), que se ha usado como referencia para elegir los temas. Los textos, ejemplos, ejercicios y explicaciones son propios. No está avalado por ninguna administración ni centro de formación y no prepara para ninguna prueba concreta: es una guía de estudio y consulta de carácter general.

> [!NOTE]
> Donde un tema toca una norma, se cita la norma y su estado. Los datos volátiles llevan año o una marca (`[no verificado]`, `[orientativo]` o `[comprobar]`). Las prácticas de laboratorio de varias unidades están escritas de memoria y avisan de que no se han ejecutado. Contrasta siempre con la fuente oficial antes de aplicarlo a un proyecto real.

## Contribuir

¿Has encontrado un error, una norma desactualizada o algo que no se entiende? [Abre una incidencia](https://github.com/ekosistema/networking/issues) o propón el cambio directamente. Lee la [guía de contribución](CONTRIBUTING.md) y el [código de conducta](CODE_OF_CONDUCT.md); para dudas, el [soporte](SUPPORT.md), y para vulnerabilidades, la [política de seguridad](SECURITY.md). En resumen, antes de enviarlo:

- Escribe en **español de España**, con todas sus tildes y sin guiones largos.
- Usa **enlaces relativos** entre ficheros y **diagramas ASCII** en bloques `text`, sin HTML ni imágenes en el contenido.
- No inventes cifras, normas ni fechas: verifica o marca `[no verificado]`.
- Ejecuta el comprobador:

```bash
node scripts/check-content.mjs
```

Para ver la web en local:

```bash
cd site
npm ci
npm run dev
```
