## El orden recomendado

```text
FUNDAMENTOS            DISENO                IMPLANTACION         ADMINISTRACION
Mercado  ----------->  Proyecto  --------->  Planificacion  ---->  Equipos
(medios, modelos,      (topologia,           (Gantt, EDT,          (IP, DNS, DHCP,
 protocolos)            cableado)             costes)               VLAN, rutas)
     |                     |                     |                     |
     |                     v                     v                     v
     |               Documentacion          Ejecucion              Gestion
     |               (tecnica, planos)      (obra, medidas,        (SNMP, monitor,
     |                                       calidad)               capacidad)
     |                                                                 |
     +-----------------------------------------------------------------+
                  Incidencias (usa todo lo anterior)
```

La lógica es la del oficio: primero entiendes la materia prima, después la diseñas, después la
construyes y al final la mantienes viva. La última unidad es la que pone a prueba las otras siete,
porque diagnosticar exige haber entendido todo lo demás.
