# Documentación técnica · Tarjetas de repaso

> **Cómo usarlas.** Tapa la columna de la derecha, contesta en voz alta y comprueba. Marca las que
> falles y vuelve a ellas a 1, 3 y 7 días. Hay 68 tarjetas en 7 bloques.

## 1. Calidad y sistema de gestión

| Pregunta | Respuesta |
| --- | --- |
| Qué certifica la ISO 9001 | El sistema de gestión, no la calidad técnica del producto |
| Edición de referencia en esta unidad | UNE-EN ISO 9001:2015 (revisión 2026 ya publicada) |
| Cuatro novedades de 2015 | Riesgos, información documentada, contexto y partes interesadas, estructura de 10 capítulos |
| Siete principios de la calidad | Cliente, liderazgo, personas, procesos, mejora, evidencias y relaciones |
| Capítulos auditables | Del 4 al 10 |
| Fases del PDCA y capítulos | Planificar (4 a 6), hacer (7 y 8), verificar (9), actuar (10) |
| Proceso, procedimiento y proyecto | Permanente; forma especificada de hacerlo; temporal con fin y presupuesto |
| Campos de una ficha de proceso | Nombre y objetivo, alcance, dueño, entradas, actividades, salidas, registros, relación con otros procesos, indicadores, riesgos y mejora |
| Niveles de la pirámide documental | Política, procedimientos, instrucciones y planos, registros |
| Qué exige el control documental | Identificar, aprobar, versión vigente, retirar obsoletos, conservar |
| Qué es un registro de calidad | Evidencia legible, fechada, firmada y recuperable |
| Qué es un plan de calidad | Aplicación del sistema a un proyecto: controles, registros y puntos de parada |

## 2. Métricas, auditoría y mejora

| Pregunta | Respuesta |
| --- | --- |
| Cuatro elementos de un indicador | Fórmula, meta, frecuencia y dueño |
| Aceptación a la primera | Armarios aceptados entre armarios entregados; meta 90 por ciento |
| Tomas fuera de límite | Tomas con parámetro en rojo entre tomas medidas; meta 2 por ciento |
| Reetiquetado | Horas de reetiquetado entre horas instaladas; meta 3 por ciento |
| Cómo se lee un indicador | Por la tendencia, no por un dato aislado |
| Tipos de auditoría | Interna, de cliente y de certificación |
| Ciclo de certificación | Tres años |
| Guía de auditoría de sistemas | ISO 19011:2018 |
| Etapas de una auditoría | Plan y lista, apertura, evidencias, hallazgos, cierre, informe y seguimiento |
| Qué hace el auditor | Contrastar evidencias con criterios; no propone soluciones |
| Tipos de hallazgo | No conformidad mayor, menor, observación y punto fuerte |
| Corrección frente a acción correctiva | Elimina el síntoma frente a elimina la causa |
| Cómo se halla la causa | Cinco porqués o espina de pescado |
