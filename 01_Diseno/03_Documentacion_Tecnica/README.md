# Elaboración de la documentación técnica

> **Diseño de redes telemáticas** · unidad 3 de 8

**En una frase.** Una red solo existe de verdad cuando alguien puede demostrar por escrito qué se diseñó, qué se instaló, quién lo autorizó, cuánto costó y con qué se comprobó; esta unidad enseña a producir ese conjunto de papeles y a defenderlo delante de un cliente, de un auditor y de un tribunal.

## Qué te llevas de aquí

- Rellenar la ficha de un proceso con entradas, actividades, salidas, registros, indicadores y mejoras, que es la primera forma del caso práctico.
- Distinguir un documento de un registro, y saber por qué esa diferencia decide quién gana una discusión con el cliente.
- Montar la estructura completa de un proyecto técnico según la UNE 157001:2014, con sus siete documentos en el orden correcto.
- Dibujar un plano de red con simbología, escala, cajetín, codificación de tomas y relación de materiales, que es la segunda forma del caso práctico.
- Cerrar una obra con acta de replanteo, libro de órdenes, certificaciones parciales, acta de recepción y liquidación final.

## El recorrido

La unidad va del sistema de calidad al plano pasando por el proyecto, que es el documento que lo une todo.

```text
   CALIDAD                  PROYECTO                  OBRA
   (que se cumpla)          (que se entienda)         (que se pueda cobrar)

 +-------------+        +------------------+       +------------------+
 | ISO 9001    |        | UNE 157001:2014  |       | direccion de     |
 | proceso     |  --->  | 7 documentos     | --->  | obra, actas,     |
 | registro    |        | + planos CAD     |       | certificaciones  |
 | auditoria   |        | + pliego         |       | + liquidacion    |
 +-------------+        +------------------+       +------------------+
        ^                                                    |
        |                                                    |
        +------------------ mejora continua <---------------+
```

## Por dónde empiezo

1. Lee el conceptual de una tirada, sin apuntar nada. La idea que hay que llevarse es que la documentación es parte de la instalación, no un trámite posterior.
2. Escucha los audioapuntes al día siguiente, andando. Fijan el vocabulario: memoria, pliego, medición, certificación.
3. Vuelve al técnico con las preguntas del conceptual en la cabeza y copia a mano las dos plantillas de procedimiento: la ficha de proceso y la elaboración de un plano.

## Antes de pasar a la siguiente unidad

- Sabes explicar sin mirar la diferencia entre pliego de condiciones y presupuesto, y por qué el pliego manda sobre el presupuesto.
- Puedes dibujar de memoria la estructura de siete documentos de la UNE 157001:2014 y decir qué pregunta responde cada uno.
- Sabes qué documento se firma al empezar la obra, cuál durante y cuál al terminar, y qué prueba cada uno.
