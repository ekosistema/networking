# Código de conducta

## Nuestro compromiso

Como personas colaboradoras y mantenedoras de Networking, nos comprometemos a que participar en el proyecto sea una experiencia libre de acoso para todo el mundo, sin importar edad, tamaño corporal, discapacidad, etnia, identidad o expresión de género, nivel de experiencia, nacionalidad, apariencia, raza, religión, orientación sexual o identidad cultural.

## Comportamiento esperado

- Usar un lenguaje amable e inclusivo.
- Respetar puntos de vista y experiencias distintas.
- Aceptar con elegancia las críticas constructivas y darlas de la misma forma.
- Centrarnos en lo mejor para la comunidad y para la calidad del material.
- Mostrar empatía, sobre todo con quien se inicia: este proyecto existe para enseñar.

## Comportamiento inaceptable

- Comentarios insultantes o despectivos y ataques personales.
- Acoso público o privado, incluida la atención sexual no deseada.
- Publicar información privada de otras personas sin su permiso.
- Trolleo, provocaciones o interrupciones reiteradas de las conversaciones.
- Cualquier otra conducta que se consideraría razonablemente inapropiada en un entorno profesional.

## Ámbito

Este código se aplica en todos los espacios del proyecto (incidencias, Pull Requests, discusiones, comentarios) y cuando alguien representa públicamente al proyecto.

## Aplicación

Los mantenedores pueden editar, ocultar o eliminar comentarios, commits, incidencias y otras contribuciones que no se ajusten a este código, y pueden limitar o bloquear, de forma temporal o permanente, a quien lo incumpla, explicando el motivo cuando sea oportuno.

## Cómo informar

Si sufres o presencias una conducta inaceptable, avísanos de forma privada:

- usa la opción **Report content** de GitHub sobre el comentario afectado, o
- escribe un mensaje privado a la persona mantenedora desde [github.com/ekosistema](https://github.com/ekosistema).

Todas las denuncias se revisarán con discreción y respeto a la privacidad de quien informa.
